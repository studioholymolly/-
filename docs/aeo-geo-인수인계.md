```
1컷 평균 30분
하프데이(실촬영 4시간) = 7~8컷
원데이(실촬영 8시간, 중식 1시간 별도) = 12~15컷
```

## 7. 함정 — 새 세션에서 반복하지 말 것

### ⛔ Vercel Git 자동 연동을 시도하지 말 것

2026-08-13에 시도했다가 되돌렸습니다. 실패 이유:

1. `claude-projects`는 **홈페이지 전용 저장소가 아님**. 견적서·캘린더 동기화·문의 처리로그 등 자동화가 수시로 `main`에 커밋
2. Git을 연결하면 **그 모든 커밋이 홈페이지 프로덕션 배포를 트리거**함
3. Root Directory가 한글+공백 경로(`홀리몰리 대시보드/홀리몰리 웹사이트`)라 빌드가 6~7초 만에 전부 Error
4. 결과: `main` 커밋마다 실패 배포가 쌓임 (사이트 자체는 무사)

**→ Disconnect로 원복 완료. 배포는 계속 수동으로.**

### 원격 세션(이 환경)이 못 하는 것

- ❌ **홈페이지 배포** — Vercel 로그인이 사용자 로컬에만 있음
- ❌ 사용자 브라우저 조작, 구글·네이버·Vercel 계정 로그인
- ❌ Vercel 프로젝트 설정 변경 (MCP에 해당 기능 없음, `get_project`도 404를 자주 냄)
- ⚠️ `curl`로 studioholymolly.com은 접근 가능. WebFetch는 403이 나므로 `curl --max-time` 사용

### 배포 방법 (사용자에게 전달할 문구)

## 8. 조사 핵심 결론 (문서 3건 요약)

1. **AEO와 GEO는 사실상 같은 작업.** GPTO는 벤더 조어이니 무시. GEO만 학술 근거 있음(KDD 2024, arXiv:2311.09735)
2. **효과 검증된 기법 3가지** — 인용문 +41%, 통계·수치 +30~40%, 출처 명시 +30%. **키워드 스터핑은 -10% 역효과**
3. **"스튜디오 추천" 키워드는 포기.** 네이버 AI 브리핑은 상업형 키워드 노출 제한, ChatGPT 로컬 추천율 1.2%. → **"질문에 답하는" 콘텐츠로 전환**
4. **링크보다 언급.** 브랜드 멘션 상관 0.664 vs 백링크 0.218 (Ahrefs 7.5만 브랜드)
5. **답변 캡슐 구조** — H2에 질문 그대로, 바로 아래 40~60단어 자립형 답변, 대명사 금지. ChatGPT 인용 페이지의 72.4%가 이 구조
6. **하지 말 것** — `llms.txt`(구글 공식 "불필요"), 멘션 구매, 숨김 프롬프트(OWASP LLM 위협 1위)

### 월 1회 점검용 프롬프트 (정보형)

ChatGPT / Perplexity / 네이버에 넣고 ① 우리 언급 여부 ② 인용 URL ③ 경쟁사를 기록:
